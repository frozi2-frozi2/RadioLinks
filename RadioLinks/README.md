# Radio Links

Текущая версия: **1.0.0**, сборка **1**. Версию можно изменить в `build.sh`; номер сборки автоматически увеличивается после каждой успешной сборки и записывается в `BuildNumber` и метаданные приложения.

Минимальное приложение для фонового прослушивания прямых URL радиопотоков. Папка проекта `RadioLinks` и готовое приложение `RadioLinks.app` находятся рядом в `RADIO`.

Вставьте скопированный на streamurl.link URL станции в редакторе ссылок. Приложение воспроизводит прямые MP3-, AAC- и HLS-потоки через AVPlayer, а для ссылок `.pls` и `.m3u` извлекает адрес потока из плейлиста. Страницы станций не принимаются. Поддерживаются HTTP и HTTPS.

Сборка из папки проекта: `./build.sh`. Скрипт собирает приложение в `../RadioLinks.app`.

Во время воспроизведения меню показывает доступные данные станции и композиции. ICY-совместимые потоки могут передавать название станции, жанр, сайт, битрейт, кодек, частоту дискретизации, число каналов и текущий трек. Для станций Laut.fm дополнительно загружаются исполнитель, название и альбом через их публичный API. Состав данных зависит от конкретной станции; если поток их не передаёт, соответствующие поля не появятся.
